# Nasooha Begam S. — Student Developer Portfolio

Responsive one-page portfolio made with HTML, CSS and JavaScript. The top navigation smoothly moves to each section: Home, About, Skills, Projects, Education and Contact.

## Preview locally
1. Download and extract this ZIP.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Double-click `index.html` to open it in a browser.

## Publish with GitHub Pages
1. Create a repository, for example `nasooha-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Open the URL shown in the Pages settings after deployment completes.

The contact form opens the visitor's default email app; it does not send messages directly. Add GitHub/LinkedIn links and any specific project technologies only when ready and accurate.
